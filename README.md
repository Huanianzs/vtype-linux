# VType Linux

在 Linux 上通过 Fcitx5 使用微信输入法 Android 引擎，支持官方云候选、个人词库同步和常用语。

**实验性源码版**：目前主要验证环境为 x86_64、Ubuntu 22.04、KDE/X11。尚未提供包含新增云功能的预编译安装包。

![七候选示例](docs/截图/七候选.png)

## 功能

- 本地拼音输入、候选翻页和选词学习。
- 官方普通拼音云候选，断网时继续使用本地候选。
- 与已关联官方客户端双向同步个人词库，支持下载全量快照。
- 同步文本常用语；优先使用官方保存的自定义编码，无编码时使用前三字首字母。F8 打开常用语列表。
- Shift / Ctrl+Space 在输入法内部切换中英；中文标点；候选数量跟随 Fcitx5 设置。

## 安装

```sh
git clone https://github.com/zhl-HFUT/vtype-linux.git
cd vtype-linux
```

按 **[安装与使用](docs/安装与使用.md)** 完成依赖安装、构建和配置。构建需要 Android NDK 和 QEMU；安装时从官方来源下载并校验指定版本的微信输入法 APK。

本地输入无需关联设备。启用云服务时，在官方客户端取得六位关联码，并按安装文档完成配对。

## 适用范围与限制

- 新增云功能目前限定 x86_64/QEMU；ARM64 原生、Wayland 和其他桌面环境尚待验证。
- 不支持语音、图片常用语和常用语编辑上传。
- 不发送上屏报告或整库快照文件；启用云候选会发送拼音查询，启用同步会传送学习词条。
- 长期离线后的自动快照恢复流程尚未完整验证；高级补拉工具仅操作已关闭的词库副本。
- 候选排序与官方客户端可能不同。
