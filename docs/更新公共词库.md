# 更新公共词库

APK 自带的是 3.5.4 版发布时的公共词库。官方之后又发布了更新的资源，其中包括**二级词库**（`slwd_second_level.bin`，补充了“倒反天罡”这类较新的词）。以下两项操作都需要先[关联设备](安装与使用.md#2-关联手机或电脑可选)。

## 下载新版公共资源

```sh
python3 scripts/prepare-public-resources.py --output ~/wetype-public-new
```

脚本会向官方查询与 3.5.4 兼容的资源，下载并校验，输出到指定目录：

- `dicts/`：完整的资源目录
- `dict_table.h`：对应的词库清单

这一步只下载，不会改动已安装的输入法。

词库清单是编译进引擎宿主的，所以要用新清单重新编译，再把新的宿主和资源一起替换进去：

```sh
cp ~/wetype-public-new/dict_table.h harness/dict_table.h
bash scripts/20_build.sh
```

替换步骤：

1. 运行 `systemctl --user stop wetype-sync.timer`，然后退出 Fcitx5（`fcitx5-remote -e`）。
2. 备份 `~/.local/lib/wetype-ime/arm64/` 下的 `wetype-harness` 和 `dicts/`。
3. 换成新编译的 `harness/jinterop` 和 `~/wetype-public-new/dicts/`。
4. 启动 Fcitx5，再运行 `systemctl --user start wetype-sync.timer`。

清单和资源必须配套。只换 `dicts/` 而不重新编译，引擎会无法启动。目前没有自动更新。

## 手动导入其他设备的完整词库

正常情况下不需要做这一步，引擎会自己同步。适用的情况是：本机词库缺少其他设备早期积累的内容，例如之前离线太久，错过了服务器保留的增量记录。

```sh
WETYPE_STATE_DIR=~/.local/state/wetype-ime/account \
  python3 scripts/pull-snapshot-copy.py --source /path/to/词库副本 --bootstrap
```

- `--source` 指向一份**已退出输入法后复制出来的**词库副本（`~/.local/share/wetype-ime/dict`）。工具会拒绝直接处理正在使用的词库。
- 工具会让官方引擎下载对端设备的快照，并合并进这份副本。合并期间副本产生的上传会被拦下。
- 不指定 `--peer` 时，默认使用关联时记录的对端设备。

导入完成后，先确认原有的词都还在、候选正常，再退出输入法，用这份副本替换正式词库。替换前一定要备份。

此工具只适用于 3.5.4 引擎，遇到其他版本会直接拒绝运行。
