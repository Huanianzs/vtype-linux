# 实验性源码版发布说明

2026-10-12。新增云功能需从源码构建，安装步骤见 [安装与使用](安装与使用.md)。

## 新增功能

官方普通拼音云候选、个人词库双向增量同步、全量快照下载、文本常用语及编码匹配，以及输入法内部中英切换、中文标点和候选序号处理。

## 验证范围

- 完整输入和同步验证环境：x86_64、Ubuntu 22.04、Fcitx5 5.0.14、KDE/X11、Android 3.5.4 引擎。
- Ubuntu 22.04 / 24.04 CI：宿主插件编译、CTest、云配置与快照传输离线检查、源码检查。
- 引擎输入、部分选词、学习、保存与重启持久化；GTK 输入框中的中英切换、标点、常用语编码和数字选词。
- AppDir 安装、状态查询和卸载；官方设备关联、个人词库增量同步及快照导入。

## 已知限制

- ARM64 原生云扩展、Wayland、其他桌面和发行版尚待完整验证。
- 长期离线后的自动快照恢复尚未完整验证；副本补拉工具不自动覆盖正在使用的词库。
- 公共资源更新需要重新构建 harness，暂不自动更新。
- 未接入整库文件上传、上屏报告、语音、图片常用语或常用语编辑上传。
- 候选排序不保证与官方客户端一致；远程桌面的长按退格行为取决于按键传递和系统重复设置。
