# 安装与使用

这是源码实验版，建议先保留现有输入法作为回退。当前云扩展只支持已验证的 x86_64 + QEMU 路线。

## 构建与安装

Ubuntu 22.04/24.04 构建依赖：

```sh
sudo apt install build-essential cmake libfcitx5core-dev file qemu-user-static e2fsprogs unzip python3 python3-cryptography libsnappy1v5 openssl curl
bash scripts/prepare_ndk.sh
export ANDROID_NDK_HOME="$PWD/.deps/tools/android-ndk-r27c"
bash scripts/e2_img.sh
./WeTypeIME-Engine-x86_64.AppImage install --user
```

打包不需要微信 APK，不包含官方引擎文件。安装阶段才从官方服务器下载固定 Android 3.5.4 APK，校验 SHA256 并在用户设备修补；也可以 `install --user --apk /path/to/file.apk` 使用本地匹配版本。NDK 和 AOSP 运行时首次构建会下载，之后复用缓存。插件按构建设备的 Fcitx5 编译，不应混用不同 ABI 的二进制。

没有 FUSE 时可设置 `APPIMAGE_EXTRACT_AND_RUN=1`。也可以在构建 AppDir 后直接安装：

```sh
bash scripts/e1_appdir.sh
bash scripts/appimage_manage.sh "$PWD/AppDir" install --user --apk /path/to/file.apk
```

完成后重启 Fcitx5，在配置中加入“微信拼音”。尚未配对时，本地输入可以独立使用。

## 关联官方客户端

安装 [wxc](https://github.com/mkdir700/wx-ime-sdk) 0.1.0；它的 npm 启动器需要 Node.js 22+。使用独立用户工具目录，不需要全局安装：

```sh
npm install --prefix "$HOME/.local/share/wetype-ime/tools" @mkdir700/wxc@0.1.0
python3 "$HOME/.local/lib/wetype-ime/arm64/wetype-cloud.py" pair --name "Linux 输入法"
```

在 Mac、iPhone 或其他官方客户端的关联设备页面获取六位码，在命令提示中输入，并在官方客户端确认关联。每台 Linux 设备需独立完成关联。

关联后主动启用：

```sh
python3 "$HOME/.local/lib/wetype-ime/arm64/wetype-cloud.py" enable --timer
```

重启 Fcitx5 后生效。`--timer` 安装用户级 `wetype-sync.timer`，约每5分钟刷新会话、组信息和常用语，不读写词库。没有 systemd 用户会话时可省略 `--timer`，自行执行 `refresh`。

通过 `--state /path/to/account` 可指定身份目录，之后保持同一路径；自定义 wxc 入口使用 `WETYPE_WXC=/path/to/wxc`。不要将状态目录放在仓库、公开网盘或多人共享目录。

## 日常使用

- 单独轻按左右 Shift 或 Ctrl+Space，在微信输入法内部切换中英。组合键中的 Shift 不应触发切换。
- 中文模式输出常见中文标点，数字小数点保留；英文模式原样输入。
- Fcitx5 全局候选数量可设为7；显示、翻页与数字选词使用同一页大小。
- 常用语使用官方客户端保存的编码；有自定义码时只认该码，没有编码才生成前三字首字母。F8 可进入常用语列表，数字编码从该列表输入。
- 主题是 Fcitx5 界面的独立配置。本项目不强制修改用户桌面主题或退格重复设置。远程桌面长按是否重复取决于按键传递与桌面重复配置。

## 状态与停用

```sh
python3 "$HOME/.local/lib/wetype-ime/arm64/wetype-cloud.py" status
python3 "$HOME/.local/lib/wetype-ime/arm64/wetype-cloud.py" refresh
python3 "$HOME/.local/lib/wetype-ime/arm64/wetype-cloud.py" disable
```

停用会关闭云配置和刷新 timer，身份与词库保留；重启 Fcitx5 后停止运行中的云代理。正常卸载使用 AppImage `uninstall --user`，保留学习数据、身份和官方资源缓存。复制配置前先备份，禁止为排查问题删除个人词库或重置身份。

## 检查

```sh
cmake -S fcitx5-wetype -B build
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tests/test_snapshot_transport.py
```

这些检查不需要账号，不发送官方业务网络请求。实际配对、多设备同步和历史词库合并需要用户自己的官方客户端验收。网络传输默认不读取代理环境变量；需要可正常联网的直连或系统 TUN 环境，失败时先检查网络/代理，不反复关联。
