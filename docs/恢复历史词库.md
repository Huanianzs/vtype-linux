# 恢复历史词库

历史词库恢复分为下载、原生导入、拼音补齐与候选验证。实时增量同步继续由官方引擎执行。以下命令在源码目录运行，均复用现有关联身份；自定义身份目录时加 `--state 身份目录`，原生补拉脚本使用环境变量 `WETYPE_STATE_DIR`。

## 检查与下载

```sh
python3 scripts/diagnose-snapshots.py
```

报告只包含匿名记录序号、元数据更新时间、地址是否一致及HTTP/COS结果，不包含设备编号、词条、密钥或签名URL。元数据列出备份、凭证申请成功，都不能保证文件仍存在；`404 NoSuchKey`表示该对象当前不可用。

```sh
python3 scripts/download-available-snapshot.py
```

下载工具优先选择关联来源设备，再查其他同组、当前密钥版本的快照。确定的对象404会继续检查其他来源；签名失败或网络错误会停止。成功文件保存在私有身份目录的 `snapshot-recovery-*`，包含 `snapshot.decrypted` 和本地来源选择文件。工具验证完整下载、解密头尾标记与数据段结构，不打开个人词库。

## 没有可用快照时请求来源设备重建

```sh
python3 scripts/request-snapshot-refresh.py
```

默认只预览同组单个关联来源设备的请求。此操作会让官方来源设备把已有个人词库备份到腾讯服务器，供当前关联组的设备同步；Linux本身不上传整库。确认来源和已有数据的共享范围后，发送一次请求：

```sh
python3 scripts/request-snapshot-refresh.py --send
```

来源设备需在线并触发官方同步；实测Mac正常输入后出现新快照。服务器接受请求不等于备份已完成，之后重新运行下载工具核对文件。工具保存私有回执，同一来源一小时内不重复提交，失败时不自动重发。

该入口用于本项目默认禁止整库上传的Linux关联身份；不会给日常代理开放通用43上报。44未返回本身份详情时使用不声明已上传备份的最小状态，不能将缺少该条目解读成服务器没有本设备状态。

完成验证或取消操作后清除本次请求，来源快照不会删除：

```sh
python3 scripts/request-snapshot-refresh.py --clear
```

## 在关闭的副本中恢复

Ubuntu需要LevelDB共享库（`libleveldb1d`）。自定义库位置可设置 `WETYPE_LEVELDB_LIBRARY`，例如Nix环境中的固定共享库路径。操作前由用户正常退出Fcitx5，把已初始化的个人词库复制到私有身份目录，形成独立的已关闭副本。工具拒绝直接使用正式目录或包含符号链接的副本。

使用下载时实际选中的来源补拉；`快照目录`为前一步生成的完整私有目录路径，`原始副本`为已关闭的词库根目录：

```sh
python3 scripts/pull-snapshot-copy.py --source 原始副本 --snapshot-dir 快照目录 --bootstrap
```

此步骤由官方引擎下载和导入各内部数据段，代理保持只读网络模式，Linux整库上传仍被阻止。结果中的 `work` 是新的隔离词库副本。下载成功和原生合并条数只表示文件被处理，不能代表所有历史拼音词已写入。

对该关闭的 `work` 副本补齐缺失拼音记录：

```sh
python3 scripts/supplement-snapshot-copy.py --source 原生导入副本 --snapshot 快照目录/snapshot.decrypted
```

命令始终复制后再写入，输出新的 `snapshot-supplement-*/work` 目录。相同拼音和词条保留已有值，其他内部数据段、同步游标、待上传学习状态保留；只有缺失词条和必要索引被追加。未知数据段由前一步原生导入处理。重复执行不会重复增加同一条词。报告中的 `source_records_missing` 应为0，仍须实际核对个人候选、重启和学习持久化。

## 正式使用

上述命令不会自动替换正式词库。隔离验证通过后，由用户选择停用输入法的时机，正常退出Fcitx5并备份当前正式词库，再用验证过的副本替换。仅当目标副本的来源、快照、候选和原有记录都已核对时执行替换。不要从日志或候选测试中复制个人词条、设备标识或签名地址到issue。
