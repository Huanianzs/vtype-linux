# 高级维护

以下操作面向能检查词库副本和构建结果的用户。日常输入不需要执行。

## 补齐公共资源

先完成官方客户端关联。固定版本资源查询会下载兼容的基础/附加资源，校验下载、解压和最终文件 MD5，只写新的暂存目录：

```sh
python3 scripts/prepare-public-resources.py --output /path/to/new-public-resources
```

输出包括 `dicts/` 和对应的 `dict_table.h`。它没有安装资源，也没有修改个人词库。需要把输出表用于重新编译 harness；仅复制新词库而不更新 `is_cell` 和版本元数据是不完整的。

在源码树重新编译的示例：

```sh
cp /path/to/new-public-resources/dict_table.h harness/dict_table.h
bash scripts/20_build.sh
```

部署前停用户同步 timer，等待当前刷新结束，正常关闭 Fcitx5 并确认引擎退出；备份安装的 harness 与公共 dicts，再一起替换已验证的构建和资源，恢复输入法及 timer。不要在运行中覆盖文件；不要删除个人词库。此阶段保留人工部署，不提供自动更新任务。

## 私有副本补拉全量快照

工具依赖系统 LevelDB C API（Ubuntu 为 `libleveldb1d`）和固定引擎散列，只接受私有副本，拒绝正式运行目录。

先正常关闭输入法并复制词库到私有目录，随后可以恢复日常输入。执行：

```sh
WETYPE_STATE_DIR=/path/to/account python3 scripts/pull-snapshot-copy.py \
  --source /path/to/closed-dictionary-copy --bootstrap --peer 官方设备编号
```

不指定 `--peer` 时读取关联结果中的对端编号。它会复制输入副本、保存原同步状态、设置本轮补拉标记，再由官方引擎下载、解密与合并；网络策略拒绝副本产生的增量上传。工具不注册设备、不改变官方设备开关、不覆盖日常词库。

运行结果保存在私有账户目录，包含词库和日志，禁止提交。成功下载不等于每条历史记录都原样保留，官方引擎可能筛选/合并。实际部署前应比较原有词条与待上传学习是否保留，并验证候选、重启及学习持久化；本工具不自动执行部署。不要用空白导入结果覆盖已有学习库。

固定 APK、ELF 状态格式和偏移只适用于当前版本。升级后工具拒绝不匹配的引擎，不能删掉版本检查强行继续。
